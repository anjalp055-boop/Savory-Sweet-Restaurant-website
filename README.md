Savory & Sweet Restaurant Website

A simple and attractive restaurant website designed for a Savory & Sweet Restaurant. This project demonstrates a restaurant-themed web page using HTML and CSS, with a clean and user-friendly design.

Project Overview

The Savory & Sweet Restaurant website provides a visually appealing online presence for a restaurant. It can be used to showcase food, restaurant information, and a welcoming dining experience.
